## запуск

1. Установить зависимости:
py -m pip install -r requirements.txt
2. Запустить приложение:
py -m streamlit run app.py
3. Открыть в браузере: http://localhost:8501

## задание 4.5

Для модели используется `st.cache_resource`, т к она загружается один раз и повторно используется приложением

Для данных и вероятностей используется `st.cache_data`, чтоб не выполнять одинаковые вычисления при изменении порога

Без кеширования `joblib.load` при каждом изменении порога заново загружал бы модель с диска, что и замедляло бы работу приложения
